# ZalogHub — список задач

Простой список задач на React + TypeScript (Vite). Без бэкенда: данные хранятся в `localStorage`.

## Возможности

- добавление задачи через поле ввода и кнопку (или Enter);
- пустую задачу и задачу из одних пробелов добавить нельзя (кнопка отключена, проверка дублируется в модели);
- переключение «выполнена / не выполнена», выполненные задачи выделены зелёным: круглый чекбокс с галочкой, светлый фон, полоска слева и приглушённый текст;
- удаление задачи;
- фильтры: все / активные / выполненные;
- счётчик оставшихся задач;
- сохранение в `localStorage` — задачи переживают перезагрузку страницы; повреждённые данные в хранилище игнорируются.

## Запуск

```bash
npm install
npm run dev        # режим разработки
npm run build      # проверка типов + production-сборка
npm run preview    # просмотр сборки
npm test           # unit- и интеграционные тесты (Vitest)
npm run typecheck  # tsc
npm run lint       # oxlint
```

## Архитектура (Feature-Sliced Design)

Импорты идут только вниз по слоям: `app → pages → features → entities → shared`.
Слайсы одного слоя не импортируют друг друга, наружу слайс открыт только через `index.ts`.

```
src/
├─ app/                  инициализация: main.tsx, App, глобальные стили и CSS-переменные
├─ pages/
│  └─ todos/             TodosPage — собирает фичи и сущность, хранит выбранный фильтр
├─ features/
│  ├─ add-todo/          форма добавления задачи
│  ├─ toggle-todo/       чекбокс выполнения
│  ├─ delete-todo/       кнопка удаления
│  └─ filter-todos/      переключатель фильтров
├─ entities/
│  └─ todo/              тип Todo, useTodos (состояние + localStorage), селекторы,
│                        валидация текста, TodoItem / TodoList (со слотами для фич)
└─ shared/
   ├─ lib/               useLocalStorage, createId
   └─ ui/                Button, Input, Checkbox
```

`TodoItem` и `TodoList` принимают фичи через слоты (`renderToggle`, `renderActions`), поэтому
сущность не зависит от фич, а страница склеивает их вместе.
